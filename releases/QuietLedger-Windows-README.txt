静账 Windows 1.1

适用：Windows 10 / 11，64 位。
双击 QuietLedger.exe，无需安装 .NET、Java、Python 或服务器，无需管理员权限。

功能：收入支出、分类、月度预算、日/周/月/年图表与排行榜、Excel (.xlsx) 导入导出、安卓 JSON 备份互通。
数据位置：%LOCALAPPDATA%\QuietLedger\ledger.json；每次保存会保留上一版 .bak。
更新：关闭程序后替换 EXE；更换 EXE 所在文件夹不会改变本机账本。
请定期导出完整 JSON 备份；文件未加密，手机和电脑不自动同步。

Excel 导入：首张表的第一行为表头。日期、金额、分类必填；收支类型为空默认支出，备注可选，编号留空自动生成。只支持 .xlsx，公式请先粘贴为数值。
JSON 完整备份含账目、分类、预算，兼容安卓版。重复数据跳过；同编号内容不同或同月份预算不同会取消整次导入。
单份账本/文件最多 10000 笔、5 MB，币种人民币。

当前为未签名的自用版本。已通过 21 项核心测试、Wine 兼容启动及四个页签显示、保存和导出检查。尚未在 Windows 实机验证。
程序包中的测试模式不会在正常启动时生成演示账目。正常首次启动为空账本。

.NET 运行时的许可证和第三方声明见 THIRD-PARTY-NOTICES.txt。
